# ukpratik/scoop-bucket

[Scoop](https://scoop.sh) bucket for [kickFile](https://github.com/ukpratik/kickfile): move files between your phone and laptop over Wi-Fi or a hotspot.

```powershell
scoop bucket add ukpratik https://github.com/ukpratik/scoop-bucket
scoop install ukpratik/kickfile
```

Update with `scoop update kickfile`.
